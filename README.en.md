# vite-plugin-file-router

#### Description
一款面向 Vite 的文件约定式路由生成插件，区别于同类虚拟模块方案，它会根据页面目录结构，直接输出可编辑、可跳转的物理 router.ts 路由配置文件，一套插件同时支持 React / Vue3 双框架，极致适配纯前端 SPA 与 Capacitor 三端 WebView 应用
